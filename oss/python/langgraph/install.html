安装 LangGraph

要安装 LangGraph 基础包：

pip

pip install -U langgraph

uv

uv add langgraph

使用 LangGraph 时，你通常需要访问 LLM 并定义工具。 你可以以任何你认为合适的方式来实现。

一种实现方式（文档中会采用）是使用 LangChain。

使用以下命令安装 LangChain：

pip

pip install -U langchain
# Requires Python 3.10+

uv

uv add langchain
# Requires Python 3.10+

如需使用特定的 LLM 提供商包，你需要单独安装它们。

有关各提供商的安装说明，请参阅集成页面。
